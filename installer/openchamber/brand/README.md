# PEMARA EDU icon

Source identity: the owner's existing PEMARA Tech orange mascot logo, preserved locally before editing. The new icon is a head-and-shoulders adaptation with a transparent background.

Created with the built-in image generation tool on 2026-10-18. Prompt: "Create a simple Windows application icon derived from the provided PEMARA tech logo. Preserve the identity of the existing friendly orange mascot, its two antennae, orange swept hair and black/dark-blue headphones. Head-and-shoulders close-up centered in a square composition, bold clean silhouette readable at 32 pixels. Remove the computer, full body and all wordmarks and tiny text. No new characters, no letters, no extra motifs. Keep the recognizable orange, black and dark blue colors, simplify small details. Actual transparent background outside the mascot, generous safe margin for antennae. Production app icon, polished but simple."

`build-icon.mjs` packages the PNG into the Windows ICO at 16, 24, 32, 48, 64, 128 and 256 pixels. It does not overwrite the source logo. PEMARA Tech branding is not licensed for third-party trademark use by the code's MIT license.
