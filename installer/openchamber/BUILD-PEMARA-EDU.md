## Windows file folders (.10)

`bootstrap.mjs` resolves the real Windows Desktop, Documents, Downloads,
Pictures, Music and Videos before isolating the AI runtime environment.
`known-folder-links.mjs` connects those ordinary folders through directory
junctions inside the private profile. This fixes native dialogs expanding
`USERPROFILE` to a nonexistent private Desktop. Existing paths are preserved;
AppData and the AI configuration remain private. No registry settings change.

Profile backups and audits must not recursively follow these junctions into
the owner's folders. Move the isolated profile as a directory or explicitly
skip reparse points when walking it. Test with
`node --test installer/openchamber/known-folder-links.test.mjs installer/openchamber/bootstrap.test.mjs`.
Installed native-dialog evidence and automation limits are recorded in
`RELATORIO-PEMARA-EDU-10.txt`.

This distribution uses the existing Electron runtime and NSIS assisted installer. There is no new compiler or framework. The teacher installs and opens PEMARA EDU; commands here are for maintainers.

## Installed real-AI regression (2026-10-19)

`real-e2e-isolation.mjs --prepare` records hashes and holds the existing clean
profile/documents before the installed application is exercised. It refuses
colliding preservation destinations. `--next-build` preserves the previous test
and installed binaries when a defect requires a new release. `--restore` moves
test output aside, restores the original profiles, and verifies every protected
file against the initial manifest; an updated installation is checked separately.
Never run these commands while the application is open.

`test-real-installed.mjs` uses the actual installed Electron executable and real
free OpenCode responses. It uploads synthetic teaching material, requests four
independent reviewers, edits and publishes through the UI, checks immutable
history, exports HTML/JSON/print output, navigates offline, exercises quiz and
Atlas controls, and reopens the saved lesson. A run with existing completed work
continues validation without requesting another generation. Logs are kept under
`evidencias/real-e2e-20261019`; this is a dated regression harness, not a reset
feature for end users. Preserve previous logs and profiles on reruns.

## Save As and teacher Word export (.9)

`release.mjs` selects the current build. The .9 desktop exports use a sandboxed
preload and a main-frame-only IPC handler. The main process owns the Save As
dialog and writes atomically to its selected destination. PDF rendering uses an
isolated hidden Chromium window with scripts and external requests disabled.
DOCX generation is lazy-loaded in the renderer and emits native paragraphs/tables
plus rasterized static diagrams. The student document omits teacher notes and
answer explanations at source; the standalone HTML retains its presentation controls.

For this dated validation, `export-v9-isolation.mjs` preserves profiles, documents
and previous installed binaries with hashes. `test-clean-installed.mjs` verifies
two empty starts; `test-installed-exports.mjs` then imports the previous real-AI
test lesson as a fixture and exercises the installed export UI. It records the
native save-dialog options and supplies test destinations/cancellation through
the dialog API; it does not click the Windows picker manually. The generation
and four-reviewer evidence remains the separate .8 real-provider run.

`test-export-documents.mjs` covers all 11 scene types. `verify-export-content.py`
checks student PDF exclusions and editable OOXML. `verify-word-export.ps1` opens
the result in Microsoft Word and can edit/save/reopen a separate copy. Native Word
rendering was used because the document skill's LibreOffice renderer was unavailable
on this Windows host. Do not rerun dated isolation scripts against restored data
without creating new preservation destinations.
