PEMARA • FERRAMENTAS PARA PROFESSORES

Instalado. Agora, vamos criar uma aula.

Abra o atalho OpenCode para aulas na Área de Trabalho e escolha Abrir OpenCode. A interface de conversa aparece em uma janela de terminal.

  1. Escolha seu provedor de IA no OpenCode. A disponibilidade de modelos gratuitos muda; este pacote não contrata serviços nem cadastra cartão.
  2. Comece pedindo um plano: “Planeje uma aula de 45 minutos sobre evaporação para o 5º ano. Sugira uma experiência segura e perguntas de avaliação.”
  3. Revise o plano. Depois peça: “Crie a aula em HTML, com todos os recursos no próprio arquivo, para abrir sem internet. Inclua controles claros para a animação.”
  4. Abra Minhas aulas, encontre o HTML e dê dois cliques para testar. Confira conteúdo, acessibilidade e funcionamento das atividades antes de usar com a turma.
O que é offline?

O instalador contém OpenCode, Python, pip, Node.js, npm e Git. A instalação não precisa de internet. A conversa com uma IA online precisa de conexão e configuração do provedor. Este pacote não inclui um modelo de IA local. Bibliotecas adicionais que cada projeto vier a pedir também precisam ser fornecidas separadamente.

Onde ficam meus arquivos?

Em Documentos → OpenCode - Aulas. Faça cópias de segurança dessa pasta. Configurações e histórico deste ambiente ficam em %LOCALAPPDATA%\PemaraOpenCodeData. Eles são preservados ao desinstalar.

Ferramentas prontas

O botão Terminal com Python, Node.js e Git abre um terminal com os comandos python, pip, node, npm, git e opencode disponíveis. Você não precisa usar comandos para instalar o pacote.

As ferramentas ficam em uma pasta própria. As instalações anteriores e o PATH global do Windows não são modificados. Atualizações automáticas e consulta automática ao catálogo de modelos ficam desativadas neste atalho. Plugins externos são desativados pelo modo --pure para uma abertura previsível.

Reinstalar ou remover

Execute o mesmo instalador para preparar outra cópia verificada; a anterior é preservada. Para remover, use Configurações do Windows → Aplicativos → PEMARA — OpenCode para aulas (offline). Aulas, configurações, versões anteriores e arquivos modificados são preservados. Pastas vazias e registros de instalação podem permanecer para conferência.

Sobre este pacote

Compatibilidade pretendida: Windows 10 e 11, 64 bits Intel/AMD ou ARM64. Windows atualizado com .NET Framework 4.8. Pacote independente de distribuição do OpenCode; não é um instalador oficial do projeto. Sem integração com o PEMARA EDU nesta etapa. O OpenCode incluído é a edição de terminal; o aplicativo Desktop existente não é modificado.

As licenças dos componentes permanecem nas respectivas pastas. Documentação oficial do OpenCode (requer internet).
